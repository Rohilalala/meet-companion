# Evidence and setup documentation

## Purpose
Preserve the requested architecture and distinguish measured feasibility evidence from blocked tests. Record no meeting media or raw chat.

## Run / test
From the repository root: `npm run preflight`, `git diff --check`.

## Debug
Keep commands, UTC timestamps, result codes, and redacted numerical observations in `FEASIBILITY.md`. Live evidence must identify its experiment and receiver; do not fabricate values.

## Landmines
Public API documentation is not live acceptance evidence. Never commit credentials, OAuth responses, raw WebRTC dumps, meeting codes, or recordings. Phase 1 acceptance is not executed in Phase 0.
